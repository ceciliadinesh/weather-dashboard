OUR PROJECT

Weather information, all in one place.

Weather Dashboard is an Angular application developed to demonstrate components, forms, routing, and API integration. It allows users to search for a city and explore important weather details through a user-friendly interface.

WHAT YOU CAN DO

Features You'll Love

Everything you need to explore current weather conditions.

City Search

Search for weather information by entering a city name.

Temperature

View the current temperature and feels-like temperature in Celsius.

Humidity

Check the humidity level to better understand the air conditions.

Wind Speed

Explore wind speed and learn more about current conditions.

Atmospheric Pressure

View atmospheric pressure as part of the current weather details.

Reliable Experience

Validate user input and display helpful messages when errors occur.
